# Visual Bible

Las Visual Bibles definen la identidad oficial de cada personaje del universo SuManada.

Incluyen:

- Rol narrativo
- Personalidad
- Apariencia
- Lenguaje corporal
- Paleta
- Reglas de ilustración
- Emoción dominante
- QA editorial

Cada personaje posee una única Visual Bible, considerada la fuente oficial para ilustradores y escritores.
